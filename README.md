# 어쩐지저녁의 SOXX — 반도체 & 매크로 라이브 데스크

**SOXX** (iShares 미국 반도체 ETF)와 **RAM** (Roundhill T-REX 2X Long DRAM Daily Target ETF, 기초자산 **DRAM** ETF), 핵심 보유 종목 20선, 그리고 전쟁·유가·채권·환율 8대 거시경제 지표를 실시간으로 추적하는 모바일 특화 금융 인텔리전스 웹앱입니다.

---

## 주요 기능

1. **실시간 전 종목 시세·차트 검색**
   - 한글 종목명(`삼성전자`, `SK하이닉스`, `한미반도체`, `마이크론`, `엔비디아` 등) 및 글로벌 영문 티커(`SOXX`, `RAM`, `DRAM`, `SOXL`, `SMH`, `TSLA`, `NVDL` 등) 실시간 자동완성 검색
2. **인터랙티브 라이브 차트 (1분봉 · 5분봉 · 15분봉 · 일봉)**
   - 모바일 터치 스크러빙(손가락 좌우 이동) 및 마우스 이동에 따라 움직이는 십자선(Crosshair)과 실시간 시가·고가·저가·종가·20선·50선 HUD 바
   - 10초 주기 실시간 현재가·캔들 자동 추적
3. **RAM 기초자산(Roundhill DRAM ETF) 월가 자금 유입 & 포트폴리오 비중**
   - 최근 5거래일 / 20거래일 기관 자금 유출입 및 실제 구성 종목 비중 시각화
4. **전쟁 · 유가 · 채권 · 환율 8대 매크로 레이더**
   - 미 국채 10년물·5년물, TLT, WTI 유가, 브렌트유, 국제 금, VIX 변동성지수, 원/달러 환율 실시간 감시
5. **SOXX & RAM 핵심 보유 종목 20선 & 글로벌 뉴스룸**
   - 상대강도(RS 1~99), 마크 미너비니 추세 템플릿(MTT), RSI(14), 20일 지지/저항선, 52주 위치 및 6대 카테고리 뉴스 40건 자동 분류

## 무료 배포 방법 (GitHub Pages 기준)

1. GitHub에서 새 저장소(예: `evening-soxx`)를 생성합니다.
2. 본 폴더의 파일 전체를 업로드(Push)합니다.
3. 저장소 상단 **Settings → Pages → Build and deployment**에서:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)` 선택 후 **Save**를 누르면 즉시 배포됩니다.
4. `.github/workflows/update_intelligence.yml` 워크플로우가 평일 30분마다 자동으로 최신 시황·자금유입·뉴스 40건을 갱신하며, 접속자 브라우저에서는 실시간 시세와 분봉/일봉 차트가 즉시 연동됩니다.
